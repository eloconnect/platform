# platform

[![CI](https://github.com/eloconnect/platform/actions/workflows/ci.yml/badge.svg)](https://github.com/eloconnect/platform/actions/workflows/ci.yml)

Plataforma do Elo Connect para um sindicato. Cobrança mensal automatizada (boleto e Pix via Sicredi), central de convenções coletivas e gestão de associados, com interface pensada para o público não técnico. Projeto Integrador do curso de DSM da FATEC Itapira.
